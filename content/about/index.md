## 关于这里

**Zero / Spatial Notes** 是我的个人技术知识库。相比碎片化的备忘录，我更希望把算法推导（如 IESKF、点面观测、因子图）与一线 C++ 工程实践（TBB 并行加速、BTC 回环优化、体素地图）写成结构清晰、配图完整、随时可复现的长文手记。

## 当前关注方向

核心聚焦在 **LiDAR–IMU 里程计（LIO）**、**3D 点云配准与位置识别**、**非线性优化（GTSAM）** 以及 **ROS / 嵌入式端侧部署**，偶尔也会整理一些提升研发体验的 Linux 与开源小工具。

## 站点技术栈

基于 **Hugo** 静态生成，保留 **Shiki** 代码高亮、**KaTeX** 数学公式渲染、**Mermaid** 流程图以及全站即时客户端筛选能力，由 GitHub Actions 自动构建发布。
